\chapter{Concepts à annoter et leurs relations}

\section{Concept BACTÉRIÉMIE}

\subsection{Définition}

Le concept BACTÉRIÉMIE identifie toute mention d'une infection bactérienne dans le sang confirmée.

\subsection{Exemples de termes à annoter}

\begin{itemize}
    \item \textbf{Termes directs} : bactériémie, septicémie, sepsis, choc septique\ldots
    \item \textbf{Termes de laboratoire} : hémoculture(s) positive(s)\ldots
    \item \textbf{Formulations cliniques} : germe dans le sang, infection sanguine\ldots
\end{itemize}

\subsection{Règles spécifiques}

\begin{enumerate}
    \item Annoter les bactériémies confirmées
    \item Les suspicions, hypothèses ou bactériémies écartées doivent être annotées avec l'attribut de négation.
\end{enumerate}

\section{Concept BACTÉRIE}

\subsection{Définition}

Le concept BACTÉRIE identifie l'agent pathogène responsable de la bactériémie, incluant toutes les variantes nomenclaturales.

\subsection{Exemples d'annotation}

\checkmark Bactériémie à [Staphylococcus aureus] résistant à la méthicilline

\checkmark Présence de [E. coli] BLSE dans les hémocultures

NB: pour référence, divers exemples de bactéries sont listés dans les annexes (voir section~\ref{sec:exemples_bacteries}).

\section{Concept SITE}

\subsection{Définition}

Le SITE identifie la porte d’entrée infectieuse.
A noter que si le site est inclus dans une expression comme porte d'entrée urinaire, il faudra annoter toute l'expression.

\subsection{Exemples d'expressions types}

\begin{itemize}
    \item point de départ
    \item porte d'entrée
    \item a pour origine\ldots
\end{itemize}

\subsection{Sites directs vs indirects}

Les sites peuvent être qualifiés selon leur mode d'identification :

\begin{itemize}
    \item \textbf{Site direct} : Mentionné explicitement dans la même phrase ou proposition.
    \item \textbf{Site indirect} : Inféré par association contextuelle, proximité dans le texte ou connaissance médicale.
\end{itemize}

NB: pour référence, divers exemples de sites sont listés dans les annexes (voir section~\ref{sec:exemples_sites}).

\section{Concept INFECTION}

\subsection{Définition}

Le concept INFECTION décrit le type spécifique d'infection associée à la bactériémie.

\subsection{Exemples non exhaustifs par système}

\begin{itemize}
    \item \textbf{Urinaire} : pyélonéphrite aiguë, pyonéphrose\ldots
    \item \textbf{Digestif} : péritonite, abcès hépatique\ldots
    \item \textbf{Pulmonaire} : pneumonie lobaire\ldots
    \item \textbf{Cutané} : érysipèle, fasciite nécrosante\ldots
    \item \textbf{Ostéo-articulaire} : ostéomyélite aiguë, arthrite septique, spondylodiscite\ldots
\end{itemize}

\section{Relations entre concepts}

Sont définies trois types de relations entre les concepts annotés : AGENT PATHOGÈNE, SITE PRIMAIRE et ORIGINE.

\subsection{Relation AGENT PATHOGÈNE}

\begin{itemize}
    \item \textbf{Type} : Bactériémie → Bactérie.
    \item \textbf{Cardinalité} : 1 bactériémie peut être causée par 1 ou N bactéries.
    \item \textbf{Exemples} : [Sepsis] → [Pneumocoque], [Bactériémie] → [S.Aureus]
\end{itemize}

\subsection{Relation ORIGINE}

\begin{itemize}
    \item \textbf{Type} : Bactérie → Site ou Infection
    \item \textbf{Cardinalité} : 1 bactérie/infection a 0 ou 1 origine identifiée.
    \item \textbf{Exemples} : [Pneumocoque] → [Origine pulmonaire], [E. Coli] → [angiocholite]
\end{itemize}

\subsection{Relation SITE PRIMAIRE}

\begin{itemize}
    \item \textbf{Type} : Bactériémie → Site ou Infection
    \item \textbf{Cardinalité} : 1 bactériémie peut avoir 0 à N site primaire.
    \item \textbf{Exemples} : [Sepsis] → [Origine pulmonaire], [Bactériémie] → [Pneumopathie]
\end{itemize}

On pourra se référer aux exemples concrets d'annotation dans la section~\ref{sec:exemples_concrets} pour plus de détails.
