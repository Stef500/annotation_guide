\section{Concepts fondamentaux de l'annotation}

\subsection{Introduction à l'annotation textuelle}

L'annotation textuelle consiste à enrichir un texte avec des informations sémantiques, syntaxiques ou pragmatiques. Cette pratique est essentielle pour :

\begin{itemize}
    \item La création de corpus d'entraînement pour l'apprentissage automatique
    \item L'analyse linguistique et la recherche en sciences du langage
    \item Le développement d'applications de traitement automatique du langage naturel
\end{itemize}

\subsection{Présentation de BRAT}

BRAT (Brat Rapid Annotation Tool) est un outil web collaboratif pour l'annotation de textes. Ses principales caractéristiques sont :

\begin{itemize}
    \item \textbf{Interface web intuitive} : Annotation directe dans le navigateur
    \item \textbf{Collaboration en temps réel} : Plusieurs annotateurs peuvent travailler simultanément
    \item \textbf{Flexibilité des schémas} : Support de différents types d'annotations
    \item \textbf{Visualisation interactive} : Représentation graphique des annotations
\end{itemize}

\subsection{Types d'annotations supportées}

BRAT supporte plusieurs types d'annotations :

\subsubsection{Entités nommées}
Identification et classification d'éléments textuels spécifiques (personnes, lieux, organisations, etc.).

\subsubsection{Relations}
Liens sémantiques entre les entités identifiées (relations de dépendance, associations thématiques, etc.).

\subsubsection{Événements}
Structures complexes impliquant des entités et leurs rôles dans des situations spécifiques.

\subsubsection{Attributs}
Propriétés et caractéristiques des entités et relations annotées.

\subsection{Architecture et fonctionnement}

BRAT fonctionne selon une architecture client-serveur :
\begin{itemize}
    \item \textbf{Serveur} : Stockage des documents et des annotations
    \item \textbf{Client web} : Interface d'annotation dans le navigateur
    \item \textbf{Formats de données} : Standoff annotation format pour la compatibilité
\end{itemize}
