\chapter{Concepts à annoter et leurs relations}

\section{Concept BACTÉRIÉMIE}

\subsection{Définition}

Le concept BACTÉRIÉMIE identifie toute mention explicite ou implicite d'une infection bactérienne dans le sang confirmée.

\subsection{Termes à annoter}

\begin{itemize}
    \item \textbf{Termes directs} : bactériémie, septicémie, sepsis, choc septique...
    \item \textbf{Termes de laboratoire} : hémoculture(s) positive(s)...
    \item \textbf{Formulations cliniques} : "germe dans le sang", "infection du sang", "passage sanguin"
\end{itemize}

\subsection{Exemples d'annotation}

\checkmark~Le patient présente une [bactériémie] à Staphylocoque doré \\
\checkmark~Diagnostic de [septicémie] sur cathéter central \\
\ding{55} Suspicion de bactériémie (non confirmée) \\
\ding{55} Hémocultures négatives (absence de bactériémie)

\subsection{Règles spécifiques}

\begin{enumerate}
    \item Annoter uniquement les bactériémies confirmées microbiologiquement
    \item Ne pas annoter les suspicions, hypothèses ou bactériémies écartées
\end{enumerate}

\section{Concept BACTÉRIE}

\subsection{Définition}

Le concept BACTÉRIE identifie l'agent pathogène responsable de la bactériémie, incluant toutes les variantes nomenclaturales.

\subsection{Exemples d'annotation}

\checkmark "Bactériémie à [Staphylococcus aureus] résistant à la méthicilline"

\checkmark "Présence de [E. coli] BLSE dans les hémocultures"

\checkmark "[Streptocoque du groupe B] isolé sur 3 flacons"

NB: pour référence, divers exemples de bactéries sont listés dans les annexes (voir section~\ref{sec:exemples_bacteries}).

\section{Concept SITE\_PRIMAIRE}

\subsection{Définition}

Le SITE_PRIMAIRE identifie la porte d’entrée initiale de la bactériémie dans l’organisme.
Si le site primaire est inclus dans une expression comme "porte d'entrée urinaire", il faudra annoter toute l'expression.

\subsection{Expressions types}

\begin{itemize}
    \item "point de départ"
    \item "porte d'entrée"
    \item "origine"
\end{itemize}

\subsection{Sites directs vs indirects}

Les sites primaires peuvent être qualifiés selon leur mode d'identification :

\begin{itemize}
    \item \textbf{Site primaire direct} : Mentionné explicitement comme source de la bactériémie dans la même phrase ou proposition.
    \item \textbf{Site primaire indirect} : Inféré par association contextuelle, proximité dans le texte ou connaissance médicale.
\end{itemize}

NB: pour référence, divers exemples de sites primaires sont listés dans les annexes (voir section~\ref{sec:exemples_sites}).

\subsection{Relation AGENT\_PATHOGÈNE}

\begin{itemize}
    \item \textbf{Type} : Bactériémie → Bactérie.
    \item \textbf{Cardinalité} : 1 bactériémie peut être causée par 1 ou N bactéries.
    \item \textbf{Exemples} : "[Sepsis] → [Pneumocoque]", "[Bactériémie] → [S.Aureus]"
\end{itemize}

\subsection{Relation PORTE\_ENTRÉE}

\begin{itemize}
    \item \textbf{Type} : Bactérie → Site\_primaire
    \item \textbf{Cardinalité} : 1 bactérie a 0 ou 1 site primaire identifié.
    \item \textbf{Exemples} : "[Pneumocoque] → [Pneumopathie]", "[S.Aureus] → [origine centrale]"
\end{itemize}

\subsection{Relation SITE\_INFECTION}

\begin{itemize}
    \item \textbf{Type} : Bactériémie → Site\_primaire
    \item \textbf{Cardinalité} : 1 bactériémie peut avoir 0 à N site primaire.
    \item \textbf{Exemples} : "[Sepsis] → [Pneumopathie]", "[Bactériémie] → [origine centrale]"
\end{itemize}

\subsection{Relation NEGATION}
\begin{itemize}
    \item \textbf{Type} : Appliquée à tout concept (BACTÉRIÉMIE, BACTÉRIE, SITE\_PRIMAIRE)
    \item \textbf{Cardinalité} : 1 concept peut être nié ou non.
    \item \textbf{Exemples} : "absence → [bactériémie]", "pas de → [sepsis]".
\end{itemize}
